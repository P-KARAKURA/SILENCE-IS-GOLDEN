# 40 Days of Silence

**A 40-day journey of reflection, discipline, and personal growth.**

## About the Project

*40 Days of Silence* is a personal reflection web application designed to encourage intentional silence, self-awareness, emotional discipline, active listening, and purposeful living.

Silence does not mean disappearing from the world or neglecting responsibilities. It means creating space to listen, think carefully, understand ourselves, and respond to life with greater intention.

This project provides a simple digital space to reflect on each day, record personal thoughts, and measure progress throughout a 40-day journey.

## Features

- **Daily reflections:** Explore a daily quote and reflection question.
- **Motivational photography:** Visual inspiration to accompany the journey.
- **Personal journal:** Write and save reflections for individual days.
- **Self-assessment:** Evaluate six personal development categories on a scale of 0–5.
- **Progress dashboard:** Track completed assessments, total points, average scores, and personal highs and lows.
- **40-day progress chart:** Visualize assessment scores throughout the journey.
- **Daily navigation:** Move between previous, current, and upcoming days.
- **Export journey:** Download your journal and assessment data as a text file.
- **Responsive design:** Use the application on desktop, tablet, or mobile devices.

## The Six Assessment Categories

Each category is scored from 0 to 5.

1. Self-control
2. Discipline
3. Listening
4. Emotional awareness
5. Respect and kindness
6. Purposeful silence

**Maximum daily score:** 30 points.

The purpose of the assessment is personal awareness and growth, not competition with others.

## Technology Stack

- **HTML5** — Application structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Daily content, navigation, assessments, and progress tracking
- **LocalStorage** — Saving journal entries and assessments in the browser

## Getting Started

### Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Make sure the following files are present:

   - `index.html`
   - `style.css`
   - `script.js`

4. Open `index.html` in your web browser.

For local development, you can also use the Live Server extension in Visual Studio Code.

### Publish with GitHub Pages

1. Push the project files to your GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under the build and deployment settings, choose **Deploy from a branch**.
5. Select your main branch and the root folder (`/`).
6. Save and wait for GitHub Pages to publish your site.

Your published website address will be displayed in the GitHub Pages settings.

## Data and Privacy

Journal entries and assessment results are stored locally in the browser using `localStorage`.

- Data is not automatically synchronized across devices.
- Clearing browser data may erase saved entries.
- The export feature allows you to download a copy of your journey.
- The application does not require a cloud database for its current functionality.

Keep exported journal files somewhere safe if you want a backup.

## Daily Reflection Moments

The journey encourages three moments of reflection:

- **6:30 AM** — Begin the day with intention.
- **1:30 PM** — Pause, observe, and reset.
- **8:30 PM** — Review the day and reflect on what you have learned.

These are suggested reflection times; the web application does not send automatic notifications.

## Project Philosophy

The goal is not to stop speaking. It is to become more intentional about when to speak, when to listen, and when to remain silent.

Silence can create room for understanding, patience, responsibility, and meaningful action.

This journey is an invitation to slow down, observe yourself honestly, and grow one day at a time.
